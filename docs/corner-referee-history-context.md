# Corner Referee History Context

## Requested feature

Add a new option under **Settings → Match History** called **“CORNER REFEREE HISTORY”**.

## Required behavior

- Record every corner-referee button press during the match.
- For each record, show:
  - Which corner referee pressed the button.
  - Which button was pressed.
  - The exact time of the press.
- Display the records in chronological order.
- Keep the history available while the match is in progress.
- Delete the corner-referee history automatically after the match ends and the winner is decided.

## Current status

This requirement has been understood and documented. No implementation changes have been made yet.
